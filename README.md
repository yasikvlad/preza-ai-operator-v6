# Продающая часть вебинара «AI-Оператор» — v6

Только продающая часть эфира: от «у вас есть два пути» до кнопки и дожима.
Вся дека — один HTML-файл, ассеты рядом. Открывается двойным кликом, ничего собирать не надо.

**Живая версия:** https://preza-ai-operator-v6.vercel.app

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` / `PREZA-EFIRA-v6.html` | сама дека: 125 слайдов, два акта — основная продажа и дожим |
| `assets/` | видео, скрины, логотипы нейросетей |
| `handoff/v6_*.py` | скрипты, которыми дека собиралась и правилась. Каждый делает одну правку и кладёт бэкап |
| `handoff/nabory_data.py` | источник правды по наборам: состав, ценность, цены |
| `audit/snap.py` | снимок любого слайда как его видит зал |
| `export-pptx-vizual.py` | экспорт в PPTX: кадр-подложка плюс живой текст поверх |
| `PRAVKI-pachka-10.md` | журнал правок: что и почему поменялось |

## Как устроена дека

Внутри три массива: `ACTS` (акты), `S` (слайды), `DIR` (шпаргалка режиссёра).
Слайд — объект: `t` заголовок, `b` тело в HTML, `k` кикер, `note` текст суфлёра,
`lv` уровень дофаминовой кривой, `dirk` имя слайда для режиссёра.

Правки делаются не руками в HTML, а python-скриптом: разобрать `var S = [`, поменять JSON,
переписать файл. Перед записью — бэкап.

Управление на эфире: стрелки, `→` вперёд. Режим `draft` показывает пометки монтажёру,
`clean` — чистый экран для зала.

## Структура

**Акт 8 — продажа.** Айсберг → два пути → программа по агентам (каждый агент на своём слайде,
со ссылкой на живой разбор его работы) → стек из 17 элементов → наборы Bronze / Silver / Gold →
цена → бронь → кнопка.

**Акт 9 — дожим.** 21 блок, каждый по схеме «контент → кейс → возврат к кнопке».
Номер блока стоит в имени слайда: `Б1 · Гарантия`, `Б8 · Дизайн и креативы`.

## Снять слайд картинкой

```
python3 audit/snap.py --deck PREZA-EFIRA-v6.html --slides 37,41,51 --out /tmp/snap
```

Нужен Playwright. Экспорт в PPTX — только `export-pptx-vizual.py`, в два прогона:
`--shoot` снимает кадры, `--build` собирает файл.
